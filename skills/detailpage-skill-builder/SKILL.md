# 상세페이지 스킬 빌더

## 언제 쓰나
참고 자료(영상·경쟁사 상세·강의)에서 **상세페이지 작성법**을 뽑아내고, 그걸 재사용 가능한 스킬로 만든 뒤 실제 제작까지 연결할 때.

## 4단계 파이프라인

### 1단계 — 분석
```
영상/자료 URL → 작성법 추출
```
- 영상이면 자막·화면을 모두 본다. 말로만 하는 팁과 화면으로 보여주는 레이아웃을 구분한다.
- 뽑을 것: 섹션 순서, 섹션별 목적, 카피 길이, 이미지 배치, 강조 방식, CTA 위치.

### 2단계 — 작성법 문서화
추출한 내용을 **순서가 있는 규칙**으로 만든다. "감성적으로" 같은 말은 규칙이 아니다.
```
섹션 1: 후킹 — 문제 제기, 1~2줄, 이미지 1장
섹션 2: 신뢰 — 인증·수상·후기 수치
...
```

### 3단계 — 스킬 생성
2단계 문서를 `SKILL.md` 로 만든다. 포함할 것:
- 언제 쓰는가 (description)
- 섹션별 작성 규칙
- 이미지 생성 지시 (어떤 도구를 쓰는지 명시)
- 금지 표현 (허위 과장, 최상급, 보증)
- 완료 체크리스트

### 4단계 — 이미지 도구 연결
```
이미지 생성은 [도구명] 을 쓴다. (예: pumasi:image, god-tibo-imagen, flux)
```
- 도구를 지정하지 않으면 매번 다른 방식으로 만들어져 결과가 들쭉날쭉해진다.
- 도구별 프롬프트 형식 차이를 스킬 안에 적어둔다.

## 한 줄 커맨드 예시
```
/insane-search <영상URL> 분석해서 상세페이지 작성법 뽑아줘.
그걸로 상세페이지 만드는 스킬 만들어줘. 이미지는 <이미지도구> 로 만들게 해줘.
```

## 금지
- **없는 인증·수상·수치를 만들지 않는다.** 실제 인증번호, 실제 판매량만 쓴다.
- 최상급 표현("최고", "1위")은 근거가 있을 때만.
- 효능·치료 표현은 식약처 규정 위반이다.

## 체크리스트
- [ ] 섹션 순서가 규칙으로 적혀 있다
- [ ] 이미지 도구가 명시돼 있다
- [ ] 금지 표현 목록이 있다
- [ ] 인증·수치에 출처가 있다
