# 모션 영상 브리프 빌더

## 언제 쓰나
영상 하나를 **기획부터 생성 프롬프트까지** 설계할 때. `video-shotlist-prompt` 가 이미 정해진 영상의 샷을 나누는 것이라면, 이 스킬은 **콘셉트·메시지·음악까지** 정한다.

## 절차

### 1단계 — 조건 확인
- 목적 (광고 / 쇼릴 / MV / 브이로그)
- 시청자
- **핵심 메시지 한 문장** (두 개면 영상이 산으로 간다)
- 길이 · 화면비
- 사용할 자산 (로고·제품컷·음원)
- 금지사항

### 2단계 — 내러티브 4구간
| 구간 | 역할 | 비중 |
|---|---|---|
| 시작 (Hook) | 3초 안에 시선 잡기 | 10~15% |
| 전개 (Build) | 문제·상황 제시 | 30~40% |
| 전환 (Turn) | 해결·반전 | 25~35% |
| 마무리 (Close) | 메시지·로고 | 15~20% |

각 구간에 **타임코드**를 배정한다.

### 3단계 — 음악 ↔ 컷 대응
음악이 있으면:
| 음악 요소 | 영상 대응 |
|---|---|
| 비트 (BPM) | 컷 길이 = 1비트 또는 2비트 |
| 드롭 | 가장 큰 장면 전환 |
| 브레이크 | 정지·클로즈업 |
| 아웃트로 | 로고·CTA |

**비트에 컷을 맞추면 싸구려처럼 안 보인다.**

### 4단계 — 생성 지시로 변환
- 색상·타이포·전환·사운드 규칙을 한 줄씩 명시
- 로고·문구는 **변형 금지**를 명시 (`do not alter the logo shape or text`)
- 참조 자산별 역할 지정

### 5단계 — 검수
- 타임코드 합계 = 총 길이
- 슬로건 글자가 정확한가
- 금지 조건이 프롬프트에 실제로 들어갔는가

## 출력 형식

```markdown
# 크리에이티브 브리프
- 목적 / 시청자 / 핵심 메시지 / 길이 / 화면비

# 샷 리스트
| # | 타임코드 | 내용 | 카메라 | 사운드 |

# 영상 생성 프롬프트
(샷별 상세)

# 사운드·금지 조건
- BGM: ...
- 금지: 로고 변형, 텍스트 오버레이, ...
```

## 체크리스트
- [ ] 핵심 메시지가 하나인가
- [ ] 타임코드 합계가 총 길이와 맞는가
- [ ] 로고·문구 변형 금지가 명시됐는가
- [ ] **확인 안 된 음원·자산 권리를 사실처럼 말하지 않았는가**
