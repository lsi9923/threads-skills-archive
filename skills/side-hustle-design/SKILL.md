# 부업 설계

## 언제 쓰나
"뭘 해서 돈 벌까"를 막연히 묻는 상황에서, **검증 가능한 계획**으로 바꿀 때.

## 절차

### 1단계 — 입력
| 항목 | 왜 필요한가 |
|---|---|
| 직무·경력 | 무엇을 남보다 잘하는가 |
| 강점 | 남이 돈 내고 물어보는 것 |
| 주당 가용 시간 | 계획의 상한 |
| 초기 자본 | 시도 가능 횟수 |
| 목표 수익 | 언제까지 얼마 |
| 제약 | 못 하는 것 (대면 불가, 야간 불가 등) |

### 2단계 — 후보 3개
경력에서 **바로 나오는 것**만. 새로운 기술을 배워야 하는 것은 3순위로.

각 후보마다:
- 고객은 누구인가
- **그들이 지금 돈을 쓰고 있는 대안은 무엇인가** (경쟁)
- 왜 나에게 올 것인가

### 3단계 — 검증 질문 만들기
후보를 확정하기 전에 **팔기 전에 물어볼 질문**을 만든다.
```
"지금 이걸 어떻게 하고 계세요?"
"그거 때문에 돈을 쓴 적 있나요? 얼마요?"
"안 하면 어떤 문제가 생기나요?"
```
→ 관심과 지불 의사를 구분한다. "좋아 보인다"는 수요가 아니다.

### 4단계 — 가격안 (가정 명시)
```
가정:
- 시간당 단가 X원 (근거: 유사 서비스 시세)
- 월 투입 Y시간
- 월 목표 Z원
계산: X × Y = Z  → 맞는가?
```
**근거 없는 수익 예측을 쓰지 않는다.** 계산식과 가정을 항상 같이 낸다.

### 5단계 — 30/60/90일
| 기간 | 목표 | 검증 지표 |
|---|---|---|
| 30일 | 첫 유료 고객 1명 | 문의 수, 전환율 |
| 60일 | 재구매 또는 소개 1건 | 재구매율 |
| 90일 | 월 목표의 50% | 월 매출 |

**지표는 숫자로.** "홍보 열심히"는 지표가 아니다.

### 6단계 — 실패 기준
```
다음 중 하나면 방향을 바꾼다:
- 60일 내 유료 전환 0
- 문의는 있는데 가격에서 전부 이탈
- 주당 투입 시간이 계획의 2배 초과
```

## 체크리스트
- [ ] 수익 예상에 가정과 계산식이 표시됐는가
- [ ] 관심과 지불 의사를 구분했는가
- [ ] 시간·자본 제약을 지킨 계획인가
- [ ] 실패 기준과 대안이 있는가
