# 스레드 콘텐츠 에디터

## 언제 쓰나
소재는 있는데 "어떤 글을 써야 사람이 멈추는가"를 정할 때.

## 1단계 — 쓰기 전에 정할 것 (출력하지 않음)

| 항목 | 질문 |
|---|---|
| 핵심 메시지 | 독자가 딱 하나만 기억해야 한다면 무엇인가 |
| 꿈의 고객 | 누가 읽어야 하는가. 나이·직업이 아니라 **무엇을 원하고, 무엇에 짜증나고, 무엇을 두려워하고, 무엇을 부러워하고, 무엇에 돈을 쓰는가** |
| 욕구 | 돈 / 시간 / 인정 / 사랑 / 매력 / 지위 / 소속감 / 자유 / 안정 / 편리 / 새 경험 / 경쟁심 / 손실 회피 |
| 후킹 | 가장 강한 사실·숫자·반전·문제·관찰·실패·주장은 무엇인가 |
| 증거 | 실제 경험·숫자·사례·대화·결과 |
| 전환 | 독자가 A라고 생각했다면 B로 바뀌는가 |
| 목적 | 조회수 / 공유 / 팔로우 / 신뢰 / 브랜딩 / 리드 / 판매 |

목적이 정해지면 구조와 CTA 강도가 달라진다. **목적 없이 쓰지 않는다.**

## 2단계 — 원칙

- 정보를 많이 주는 것보다 **하나의 생각을 강하게** 심는다.
- 한 글에 주장 여러 개를 억지로 넣지 않는다.
- 원문이 길어도 핵심이 하나면 **과감히 버린다**.
- 원문 순서를 그대로 따라가지 않는다. 강의는 목차 순서, 인터뷰는 질문 순서, 후기는 광고 문구 순서로 쓰지 않는다.
- 모든 소재는 핵심 메시지를 증명하는 방향으로 **재배치**한다.

## 3단계 — 첫 줄

첫 줄에서 스크롤을 못 멈추면 뒤는 없는 것과 같다.

**금지 도입부**
- "요즘 ~가 중요합니다."
- "많은 사람들이 ~합니다."
- "오늘은 ~에 대해 이야기해보겠습니다."
- "혹시 ~해보신 적 있나요?"

**허용 후킹 유형 (10종)**
| 유형 | 예 |
|---|---|
| 결과형 | "첫 영상 하나로 팔로워 1만 명이 늘었습니다." |
| 실패형 | "월 천만 원을 찍고 오히려 방황하기 시작했습니다." |
| 역설형 | "사업 하나를 내려놨는데 매출은 오히려 올라갔습니다." |
| 통념 반박형 | "열심히 글 쓰는 사람이 오히려 스레드에서 안 터지는 이유가 있습니다." |
| 손실 회피형 | "이걸 모르고 광고 돌리면 돈만 계속 새어나갑니다." |
| 숫자형 | "글 하나 바꿨는데 문의가 4배 늘었습니다." |
| 권위형 | "현직 텍스트 마케팅 회사 대표인데, 초보들이 가장 많이 하는 실수 말해드리겠습니다." |
| 관찰형 | "조회수는 잘 나오는데 돈은 못 버는 계정을 보면 공통점이 있습니다." |
| 직접 인용형 | "대표님, 조회수는 터졌는데 왜 아무도 안 사죠?" |
| 강한 단정형 | "흔한 정보를 올리는 것보다 더 위험한 게 있습니다." |

'많이·빠르게·엄청난·좋은'은 실제 숫자나 상황으로 바꿀 수 있으면 바꾼다.

## 4단계 — 통념 건드리기

그대로 말하는 글은 지나간다.
- **통념 극대화**: 알려진 사실을 극단까지 밀어붙인다.
- **통념 충돌**: 당연하다고 여기는 A와 반대되는 B를 붙인다.

## 5단계 — 자기 검수

- [ ] 핵심 메시지가 하나인가
- [ ] 첫 줄이 금지 도입부 중 하나가 아닌가
- [ ] 숫자를 만들어내지 않았는가
- [ ] 목적(조회수/신뢰/판매)에 맞는 CTA인가
- [ ] 원문 순서를 그대로 옮기지 않았는가
