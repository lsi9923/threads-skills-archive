# 블로그 콘텐츠 파이프라인

## 언제 쓰나
주제 하나를 받아 **조사 → 키워드 → 개요 → 초안 → 메타데이터 → 발행 확인**까지 한 번에 갈 때.

## 절차

### 1단계 — 입력 확인
- 대상 독자 (누가 읽나)
- 주제 / 핵심 주장 (한 문장)
- 참고 사이트·자료
- 말투 (정보형 / 후기형 / 설명형)

**근거와 추정을 구분한다.** 확인 안 된 수치는 쓰지 않는다.

### 2단계 — 키워드·검색의도
| 구분 | 예 |
|---|---|
| 메인 키워드 | 1개 |
| 서브 키워드 | 3~5개 |
| 검색 의도 | 정보 탐색 / 구매 전 비교 / 문제 해결 |

경쟁 글 3개를 보고 **빠진 각도**를 하나 정한다. 같은 말 반복은 순위가 안 오른다.

### 3단계 — 개요
```
제목안 3개 (각각 다른 각도)
도입: 독자가 겪는 상황 1문단
소제목 4~6개 (각각 한 가지 주장)
마무리: 요약 + 다음 행동
```

### 4단계 — 초안
- 사용자가 준 말투·사례를 쓴다.
- 문단은 3~4문장. 한 문단에 한 주장.
- 출처가 필요한 주장에는 링크를 붙인다.
- **확인 안 된 체험담을 만들지 않는다.**

### 5단계 — 메타데이터 (초안과 분리)
| 항목 | 주의 |
|---|---|
| 제목 | 25~35자, 본문 내용과 일치 |
| 요약문 | 80~120자, 과장 금지 |
| 카테고리 | 1개 |
| 태그 | 5~10개, 본문에 실제로 다룬 것만 |

### 6단계 — 발행 (사용자 확인 필수)
- **미리보기를 먼저 보여준다.**
- 발행·예약 시각은 사용자가 명시적으로 확인한 뒤에만 실행한다.
- 예약 발행은 취소가 어려우므로 특히 확인을 받는다.

## 체크리스트
- [ ] 출처 필요한 주장에 근거가 있는가
- [ ] 키워드가 실제 내용과 맞는가
- [ ] 메타데이터가 본문을 과장하지 않는가
- [ ] 발행/예약을 확인 없이 실행하지 않았는가
