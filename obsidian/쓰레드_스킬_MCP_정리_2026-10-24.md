## 1. 프롬프트는 '단어'가 아니라 '모양'으로 걸렀다

처음엔 "프롬프트"라는 **단어가 있으면** 다 골랐더니 104건이 나왔고, 대부분은 감상이었습니다.

> "후자입니다! 프롬프트 한번으로 알아서 해주더라고요" — 이건 지시문이 아니라 감탄입니다.

그래서 판정 기준을 바꿨습니다. **둘 다** 갖춰야 인정:

1. **역할 부여** — `당신은` / `너는` / `You are` + 역할 명사
2. **산출물 요구** — `~해 주세요` / `작성해` / `write` / `generate`

번호만 나열한 질문지(사업자 진단, AI 도구 소개)는 역할 부여가 없어 **탈락**입니다.
결과: 674건 전체에서 **진짜 지시문 5건**.

## 4. MCP 서버 8개

MCP는 AI에게 손과 발을 달아주는 것입니다. 없으면 말만 하고, 있으면 실제로 찾아옵니다.

| MCP | 하는 일 | 상태 |
|---|---|---|
| `google-surf` | 구글 검색 | 기존 |
| `rea` | 프로그램 뜯어보기(리버스 엔지니어링) | 기존 |
| `google-flow` | 이미지·영상 생성 | 기존 |
| `kit-for-ai` | 지식 저장고 | 기존 |
| `muse` | 무스 비서 | 기존(복구) |
| `korean-law` | 법령·판례·조례 검색 | **신규** |
| `chrome-devtools` | 브라우저 개발자 도구 | **신규** |
| `gitnexus` | 코드 저장소 분석 | **신규** |

**신규 3개는 MCP 핸드셰이크까지 실제로 확인**했습니다:
- `korean-law` → `serverInfo: korean-law 4.15.9`
- `chrome-devtools` → `serverInfo: chrome_devtools 1.12.0`
- `gitnexus` → `serverInfo: gitnexus 1.6.12`

### 아직 못 쓰는 것 (API 키 필요)

| 패키지 | 막힌 이유 |
|---|---|
| `korean-stats-mcp` | `KOSIS_API_KEY` 필요 → [kosis.kr/openapi](https://kosis.kr/openapi/) |
| `korean-dart-mcp` | `DART_API_KEY` 필요 → [opendart.fss.or.kr](https://opendart.fss.or.kr/) |

두 곳 모두 **본인 명의 회원가입 + 휴대폰 인증**이 필요합니다. 대리 가입은 불가능합니다.

## 5. 무스(Muse) 복구 기록

Muse가 두 가지 이유로 죽어 있었습니다.

| 문제 | 해결 |
|---|---|
| `muse-mcp`는 `mcp<2`를 요구하는데 전역엔 2.3.0 → 서버 시작 불가 | 전용 venv `~\.muse-mcp-venv\` (mcp 1.30.0). 전역 환경은 손대지 않음 |
| 쿠키 만료(401) | Chrome CDP로 재추출. 612 → 1,762바이트, `hatch_sess` 포함 |

> Chrome 155는 기본 프로필에서 디버깅 포트를 막습니다 → 별도 `--user-data-dir` + `--remote-allow-origins=*` + `Storage.getCookies`로 우회.
> `browser_cookie3`은 앱 바인딩 암호화 때문에 관리자 권한 없이 실패합니다.

**무스에는 스킬 시스템이 없습니다.** CLI 22개 하위명령에 `skill`이 없고, 소스에 `skill` 참조 0건이며, `~/.config/muse-cli/skills`(1개: notebooklm)는 코드에서 읽지 않습니다. 그래서 무스에는 스킬을 깔지 않았습니다.
